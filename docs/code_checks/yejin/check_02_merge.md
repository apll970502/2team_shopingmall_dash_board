## 4. 실행 코드
# 주문 금액 계산 (수량 × 단가)
order_items["total_amount"] = (
    order_items["quantity"] * order_items["unit_price"]
)

# 데이터 병합
df = order_items.merge(products, on="product_id", how="left")
df = df.merge(orders, on="order_id", how="left")
df = df.merge(customers, on="customer_id", how="left")

# 병합 결과 확인
print("병합된 데이터 크기:", df.shape)

df.head()

## 6. 정상 조건 검증

- product_id, order_id, customer_id를 기준으로 데이터를 순서대로 병합하였다.
- 최종 데이터의 크기가 (14603, 18)로 확인되어 정상적으로 병합되었다고 판단하였다.

## 8. AI 코드에서 수정한 부분
1. 주문 금액을 quantity * unit_price로 계산하도록 작성하였다.
2. 여러 데이터를 각각의 ID를 기준으로 left merge하도록 작성하였다.

## 10. 아직 이해되지 않는 부분
