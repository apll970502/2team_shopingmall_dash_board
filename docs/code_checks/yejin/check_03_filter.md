## 4. 실행 코드
# 쇼핑몰 핵심 지표 계산

total_customers = df["customer_id"].nunique()
total_orders = df["order_id"].nunique()
total_revenue = df["total_amount"].sum()

aov = total_revenue / total_orders if total_orders > 0 else 0

print("=== 쇼핑몰 핵심 지표 ===")
print(f"고객 수: {total_customers:,}명")
print(f"총 주문 건수: {total_orders:,}건")
print(f"총 매출액: {total_revenue:,.0f}원")
print(f"평균 주문 금액(AOV): {aov:,.0f}원")

## 5. 실제 결과
- 출력값:
 고객 수: 1,102명
 총 주문 건수: 6,000건
 총 매출액: 1,837,774,300원
 평균 주문 금액(AOV): 306,296원
- 예상과 다른 점: 오류 없이 핵심 지표가 정상적으로 계산되었다.

## 6. 정상 조건 검증
- 고객 수는 customer_id의 중복을 제외하여 계산하였다.
- 주문 건수는 order_id의 중복을 제외하여 계산하였다.
- total_amount를 모두 더하여 총 매출액을 계산하였다.
- 총 매출액을 총 주문 건수로 나누어 AOV를 계산하였다.
- 주문 건수가 6,000건으로 0보다 크므로 AOV 계산이 정상적으로 이루어졌다.

## 7. 예외 조건 검증   [주의] 6번의 반복이면 안 됨
- 조건: 총 주문 건수가 0인 경우
- 결과: if total_orders > 0 else 0 조건을 사용하여 0으로 나누는 오류가 발생하지 않도록 작성하였다.

## 8. AI 코드에서 수정한 부분
1. 고객 수와 주문 건수를 중복 없이 계산하기 위해 nunique()를 사용하였다.
2. 총 매출액은 sum()으로 계산하고, AOV는 총 매출액을 총 주문 건수로 나누도록 작성하였다.

## 9. 내 말로 설명
고객 수, 주문 수, 총 매출액을 먼저 계산한 다음,
총 매출액을 주문 수로 나누어서 평균적으로 한 번 주문할 때 얼마를 사용하는지 나타내는 AOV를 계산하는 코드이다.
